# Personal Mini-Toolkit

A modular Python command-line application built as the final project for PLP Python Week 8.

## Description
This application provides a central menu system accessing three utility tools:
1. **Number-Guessing Game**: Generates a secret number and prompts the user to guess it with low/high feedback.
2. **Interactive To-Do List**: Allows continuous adding, viewing, and dynamic removal of tasks.
3. **Simple Tip Calculator**: Computes exact tip amounts and splits bills evenly among a given group.

## Features
- Main loop menu structure that prevents program crashes from non-numeric or out-of-bounds options.
- Dynamic list operations for real-time task management.
- Robust input handling with custom error notifications.
